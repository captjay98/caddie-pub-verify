# Scope: Caddie

### Kernel
An AI chief-of-staff for solo hackathon builders that audits fine print, sharpens POC scope, enforces planning discipline, and provides unsparing judge reviews before submission.

### Target Audience
Solo developers and lean teams (e.g. 10–15h/week budget) building fast POCs who risk disqualification from buried contest rules or wasted time from scope creep.

### Core Loop
`Contest URL & idea` -> `Extract verbatim rules & fit verdict` -> `Sharpen kernel & generate scope/prd/spec` -> `Push private repo` -> `Pre-submission judge review`.

### POC Boundary
- **In Scope:**
  - Devpost rules parser with verbatim claim extraction and ISO deadline stamping.
  - Socratic ideation sharpen engine enforcing single-loop POC scope.
  - Three-file planning doc generator (`scope.md`, `prd.md`, `spec.md`).
  - GitHub repo creation and file commit pipeline.
  - Rubric-based judge review scorecard with honest risk analysis.
- **Cut List:**
  - Multi-user teams or real-time co-editing.
  - Autonomous submission to Devpost.
  - Automated video recording or screencast generation.
  - Non-Devpost platform scrapers.
