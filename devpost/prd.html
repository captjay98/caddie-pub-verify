Expand — behaviors & states

Features (POC)
  • Profile — stack, hours/week, goals (local)
  • Discover — Devpost only, fit-ranked
  • Extract + fit — cited rules, verdict
  • Ideate — one kernel + scope line on The Card
  • Plan — skill-pack quality scope/prd/spec
  • Start — GitHub repo + push those three docs
  • What changed — re-check, impact-ranked diff
  • Judge review — vs plan + judging criteria
States
  • First use — “No contest on the bag yet” + Find a hackathon
  • Fetch fail — red card, last-good snapshot, Retry; never a fake brief
  • No search hits — honest empty copy
  • No rule delta — quiet
  • Persistence — profile, snapshots, plans, repo URL local
  • Human submits — always
Deferred / non-goals
  • OAuth accounts · scheduler · push · MLH · teams · mobile · submit-for-you
  • Not social, not marketplace, not a todo app, not multi-tenant SaaS
