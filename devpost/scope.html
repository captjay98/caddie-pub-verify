Caddie

An agent caddie for hackathons — finds the fit, sharpens the idea, writes the plan, creates the repo, and reviews you like a judge before you submit. It carries the bag; you swing.

Markdown is canonical (devpost/scope.md). This page is only for reading the plan.

The Unique Kernel

Not a summarizer. Not a dashboard. An agent that takes a busy builder from “which hackathon?” → planned repo on GitHub → judge-style review before submit.

Delete the plan→repo and judge review actions and this is just chat with search. That’s the kernel.

Who it’s for

Busy builders with a full-time job and a side gig who enter hackathons — starting with the founder. They can ship products. They lose to fine printscope creepbad presentation

What “working” looks like (the demo)

Under 3 minutes on screen:

  • Profile exists (stack, hours/week, goals)
  • Chat: “find me a hackathon” → Devpost matches with fit reasons
  • Rules cited (deadline, eligibility, must-dos)
  • Idea sharpened to one kernel
  • scope / prd / spec generated
  • GitHub repo created with those three docs inside
  • Fast-forward: judge-style review vs plan + judging criteria

oh-that’s-cool beat the repo appears with the plan already inside — and the review does not flatter.
