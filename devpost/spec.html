Caddie — technical blueprint

TanStack Start on Cloudflare Workers · D1 · Vercel AI SDK · server-side tools. Keys stay on the server. The Card and chat are one surface.

Canonical: devpost/spec.md

Plain language

Chat is a caddie that can use tools. Tools run on a Cloudflare Worker — fetch Devpost, extract cited claims, write plans, create a GitHub repo, re-check rules, judge-review. Data lives in D1. The Card is the brief; chat is the radio. No browser secrets. No scheduler in the POC.

Failure modes & simplifications
  • Fetch fail → danger card + last-good + retry · never fake claims
  • LLM key fail → explicit chat error
  • GitHub 403 → skip repo step with a clear message
  • Simplified: no scheduler · PAT not OAuth · Devpost only · env provider
